LZ79 Freelance — Web v1
=======================

Portada completa y responsive para LZ79 Freelance.

Incluye: hero empresarial con Galia Chat; Galia en modo pruebas; chat frontend demo sin API key; buscador flotante demo; productos LZ79 Essential, comandas e inventario; sección Pro; IA; público objetivo; servicios; contacto; responsive.

IMPORTANTE: es una web estática. No contiene claves de OpenAI, Google ni otros proveedores. El chat y buscador son demos locales. Para producción se conectará el backend/proveedor de búsqueda y, si se desea, la IA.

Para probar: abre index.html. Para publicar en GitHub Pages, sube el contenido de esta carpeta al repositorio.

Cambia el correo de contacto en index.html si contacto@lz79freelance.com no es el definitivo.
