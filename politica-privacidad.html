Política de Privacidad – LZ79freelance

1. Responsable del tratamiento

El responsable del tratamiento de los datos es el titular de LZ79freelance, con domicilio en O Porriño (Galicia, España). El tratamiento se rige conforme al Reglamento (UE) 2016/679 (RGPD) y la Ley Orgánica 3/2018 (LOPDGDD).

2. Datos que recopilamos y dónde se almacenan

La aplicación está diseñada bajo el principio de minimización de privacidad. Los datos de clientes, proveedores, importes y conceptos introducidos en la app se guardan exclusivamente de forma local en la base de datos interna del dispositivo del usuario (contabilidad.db). No se envían a servidores externos ni nubes de terceros.

3. Finalidad del tratamiento

Los datos introducidos voluntariamente se procesan localmente con la única finalidad de permitirle gestionar su contabilidad, mantener el registro de contactos y exportar informes formateados para su gestoría.

4. No cesión de datos a terceros

Al no utilizar servidores en la nube ni plataformas externas, no se ceden, venden ni transmiten datos personales a ninguna empresa, proveedor tecnológico ni servicio externo.

5. Seguridad de los datos

La aplicación implementa mecanismos de control internos en el almacenamiento local, como el encadenamiento mediante funciones de resumen criptográfico Hash SHA-256 para garantizar la trazabilidad de los movimientos contables.

6. Derechos del usuario

Dado que la base de datos reside íntegramente en su propio dispositivo, el usuario tiene el control absoluto: puede consultarlos, modificarlos o eliminarlos directamente desde la aplicación o borrando el archivo de base de datos local en cualquier momento.
